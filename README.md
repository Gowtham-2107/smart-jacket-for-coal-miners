# Smart Jacket for Coal Miners

An IoT-based wearable safety system designed to improve the safety of coal miners by monitoring vital signs and environmental conditions in real time using ESP32 and LoRa communication.

## Features

- Real-time heart rate monitoring
- Body temperature monitoring
- Environmental condition sensing
- Long-range LoRa communication
- Emergency alert system
- Low-power wearable design

## Technologies Used

- ESP32
- Embedded C
- Arduino IDE
- LoRa Module
- IoT Sensors

## Project Objective

This project aims to enhance miner safety by continuously collecting health and environmental data and transmitting it wirelessly to enable faster emergency response in hazardous underground mining environments.

## Future Improvements

- Gas detection integration
- GPS tracking (surface monitoring)
- Mobile app dashboard
- Cloud-based data logging
